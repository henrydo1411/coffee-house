# Coffee House

Web đặt đồ uống: React + Express + MongoDB.

## Chạy local

Backend:
    cd backend
    npm install
    cp .env.example .env    # rồi điền giá trị thật
    npm run seed
    npm run dev

Frontend:
    cd frontend
    npm install
    npm start

## Công nghệ
React, React Router, Axios, Express 5, Mongoose, JWT, bcrypt, helmet.

## Tài liệu
Xem API.md để biết danh sách endpoint.
